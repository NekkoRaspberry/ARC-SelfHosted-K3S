K3S Adventure

Self-hosted GitHub Actions runners (ARC) on a Raspberry Pi 4 running K3s.

Setup

  • Device: Raspberry Pi 4 Model B (8 GB)
  • OS: Raspberry Pi OS Lite 64-bit
  • Kubernetes: K3s
  • Runners: Actions Runner Controller, label nekko-runners

Workflows

  • ARC Runner Test checks that the Pi runner works
  • Auto Assign Issues and PRs assigns new issues and PRs
  • HTML Link Checker checks this page for broken links
